# Robiul Predictor & Hacker Tool (V2)

Official high-performance Wingo 30s & 1min prediction and analytics engine powered by 10 AI models ensemble under Evil Mode, dual-role authentication, dynamic link management, 7-day trial restriction, and multi-device licensing.

## Features
- **10 AI Models Ensemble:** Deep AI voting core with cross-verification.
- **Dual-Role Auth:** Admin & Normal trial access roles.
- **Dynamic Link Management:** Update Wingo referral link and passwords directly from the Admin Panel.
- **7-Day Trial Lock:** Enforces referral registration after 7 days.
- **Daemon Auto-Start:** Run permanently in background via `start_daemon.sh`.

## Quick Start
1. Run server in background:
   ```bash
   bash start_daemon.sh
   ```
2. Access locally:
   `http://127.0.0.1:5000`
